# 🎵 AUDIOKILL

**Audiokill** is an intentionally rage-inducing, brutalist web app built for the **Chaos of Design** contest, designed to weaponize terrible UX and drive its users completely insane through a series of diabolical psychological hurdles.

---

## 📸 Interface Preview & Features

### 1. The Hydra-Password Gauntlet
*Users enter a fake name and face an escalating password screen with dynamically spawning rules.*

![Password Gauntlet Screen](https://raw.githubusercontent.com/rust-spielberg/Chaos_Prototype/main/visuals/Screenshot%202026-10-13%20at%2012.36.52%20AM.png)

### 2. The Gaslighting Captcha
*A human-verification puzzle forcing users to hunt for a single hidden correct tile among trolling options.*

*A massive, unclosable consent banner mocking the user's lack of options.*
